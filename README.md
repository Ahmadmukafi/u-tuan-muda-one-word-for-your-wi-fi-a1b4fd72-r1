One word that describes my Wi-Fi: **haunted**.

It appears and vanishes on its own schedule, drops out at 3 AM for no reason,
and reconnects the moment you stop watching it. Every dead zone in the house
feels like a room it refuses to enter. The word is both the joke and the
diagnosis — a network that behaves less like infrastructure and more like
something that was never quite alive to begin with.

## Run

```sh
node main.ts
```

Writes `entry.txt` (7 bytes, no trailing newline) to `MAKEFUN_OUTPUT_DIR`
or `/output`.
